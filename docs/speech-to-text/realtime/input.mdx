# Input

## Supported input audio formats
Sessions can be configured to use two types of audio input: `file` and `raw`.  
We recommend using the `raw` option, unless you have a specific reason to use the `file` option.

:::tip
For capturing raw audio in the browser, try our [`browser-audio-input` package](https://www.npmjs.com/package/@speechmatics/browser-audio-input).
:::

### `audio_format`

The format must be supplied in the `audio_format` field of the `StartRecognition` message. See the [API reference](/api-ref/realtime-transcription-websocket#start-recognition).

## Language hints

Language hints are optional and apply only to the [Melia 1](/speech-to-text/models#melia-1) and [Oak 1](/speech-to-text/models#oak-1) models, which detect supported languages automatically. For the Enhanced and Standard models, set `language` to a [supported language](/speech-to-text/languages) instead.

Set `language_hints` in the `StartRecognition` message to the [supported languages](/speech-to-text/languages#transcription-languages) you expect in your audio. Hints have two effects:

- **Language labels are restricted to the hinted languages.** Every word in the transcript is labelled with one of the languages you list.
- **Transcription is biased toward the hinted languages.** This can improve accuracy, especially for short utterances and similar-sounding languages.

Speech in other languages may still be transcribed in some cases, but it is labelled as one of the hinted languages. Only use hints when you know which languages your audio contains.

With one hint, the whole session is labelled as that language. With two or more, labels can switch between the hinted languages. This config hints that the audio contains English and Arabic:

```json
{
  "message": "StartRecognition",
  "audio_format": {
    "type": "raw",
    "encoding": "pcm_s16le",
    "sample_rate": 16000
  },
  "transcription_config": {
    "model": "melia-1",
    // Melia 1 requires "multi" rather than a single language code
    "language": "multi",
    // highlight-start
    "language_hints": ["en", "ar"]
    // highlight-end
  }
}
```

:::note
Speechmatics language hints restrict output rather than only biasing it. Unlike hints that make listed languages more likely, they exclude unlisted languages from labelling.
:::

To render each detected language correctly, refer to the [`LanguageInfo` message](/speech-to-text/realtime/output#languageinfo-message).

## Sending audio

After receiving a `RecognitionStarted` message, you can start sending audio over the Websocket connection. Audio is sent as binary data, encoded in the format specified in the `StartRecognition` message. See [Protocol overview](/api-ref/realtime-transcription-websocket) for complete details of the API protocol.
