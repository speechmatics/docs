Each language is uniquely identified by a two-letter code (ISO 639-1) or three-letter code (ISO 639-3) in API requests and responses. Set the code with the `language` property in your transcription config.

Your ability to use any or all of these languages depends on the languages you are contracted to use. To read the current language set at runtime rather than from this page, use [feature discovery](/speech-to-text/features/feature-discovery).
