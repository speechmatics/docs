# PII Redaction

**Available in:** Batch, in Speechmatics SaaS on all [models](/speech-to-text/models). Not available in Realtime, Agent STT, or on-prem deployments.

PII Redaction removes sensitive data, such as names, dates of birth, health conditions, and credit card numbers, from a Batch transcript. Each redacted value is replaced with a label for its entity class, such as `[name_given]`.

## Enable PII Redaction

To enable PII Redaction, set `enable_redaction` to `true` and list what to redact in `redaction_config.entity_classes`:

```json
{
  "type": "transcription",
  "transcription_config": {
    "language": "en",
    "enable_redaction": true,
    "redaction_config": {
      "entity_classes": ["gdpr"]
    }
  }
}
```

## Choose what to redact

Each value in `redaction_config.entity_classes` is either an entity class group or a specific entity class. You can mix both in one list. Start with the regulation group that matches your compliance requirements, then add or remove specific entity classes to match your own data handling guidelines.

- **Regulation groups**: `gdpr`, `gdpr_sensitive`, `hipaa_safe_harbor`, `cpra`, `quebec_privacy_act`, `appi`, and `appi_sensitive`. Each covers the entity classes a regulation treats as personal or sensitive data.
- **Data type groups**: `health` (protected health information), `pci` (payment card information), and `pii` (personally identifiable information).
- **Specific entity classes**: for example `name_given`, `dob`, or `credit_card`. A general class such as `name` or `location` also redacts its subclasses, such as `name_given` or `location_city`.

`pii` is broad. It covers every class in the [PII table](/speech-to-text/features/entity-detection-classes#personally-identifiable-information-pii), including dates, times, amounts of money, and organization names, so it redacts much more than the values that identify a person. Use it only when you want all of these removed.

For example, this configuration redacts everything covered by GDPR, plus given names and credit card numbers:

```json
{
  "type": "transcription",
  "transcription_config": {
    "language": "en",
    "enable_redaction": true,
    "redaction_config": {
      "entity_classes": ["gdpr", "name_given", "credit_card"]
    }
  }
}
```

If `enable_redaction` is `true` and `redaction_config.entity_classes` is missing, the job is rejected.

For every entity class and the groups that include it, see [Entity Detection classes](/speech-to-text/features/entity-detection-classes).

## Redacted output

For the utterance "Mark was born on the 25th of July 2000.", the redacted JSON transcript looks like this (timings omitted):

```json
{
  "results": [
    { "type": "word", "alternatives": [{ "content": "[name_given]", "speaker": "S1" }] },
    { "type": "word", "alternatives": [{ "content": "was", "speaker": "S1" }] },
    { "type": "word", "alternatives": [{ "content": "born", "speaker": "S1" }] },
    { "type": "word", "alternatives": [{ "content": "on", "speaker": "S1" }] },
    { "type": "word", "alternatives": [{ "content": "the", "speaker": "S1" }] },
    { "type": "word", "alternatives": [{ "content": "[dob]", "speaker": "S1" }] },
    { "type": "punctuation", "alternatives": [{ "content": ".", "speaker": "S1" }] }
  ]
}
```

PII Redaction removes the original values throughout the JSON transcript.

## Use PII Redaction with Entity Detection

PII Redaction works on its own. To also label each detected value with its entity class, enable [Entity Detection](/speech-to-text/features/entity-detection) in the same job. Redacted values are then returned as `entity` results with an `entity_class`.

If `enable_entities` is `true` in a job with PII Redaction, `entities_config.detect_advanced_entities` must also be `true`. Otherwise, the job is rejected. PII Redaction can't be combined with [smart formatting entities](/speech-to-text/formatting#smart-formatting).

When PII Redaction is enabled, the transcript has no `spoken_form` or `written_form`.

## Supported languages for PII Redaction

PII Redaction supports all [transcription languages](/speech-to-text/languages#transcription-languages), except:

- Bashkir
- Basque
- Esperanto
- Galician
- Interlingua
- Irish
- Maltese
- Marathi
- Mongolian
- Urdu
- Uyghur
- Welsh

For Mandarin, use the Simplified [output locale](/speech-to-text/formatting#output-locale) (`cmn-Hans`, the default). PII Redaction of Traditional characters (`cmn-Hant`) isn't supported yet.
