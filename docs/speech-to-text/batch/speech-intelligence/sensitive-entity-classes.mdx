# Sensitive entity classes

[Sensitive data recognition](/speech-to-text/batch/speech-intelligence/sensitive-data-recognition) labels each detected value with one of the entity classes below. [Redaction](/speech-to-text/batch/speech-intelligence/redaction) accepts these entity classes and the groups in [Entity class groups](#entity-class-groups).

Some entity classes have subclasses. For example, `location_city` is a subclass of `location`, and `name_given` is a subclass of `name`. Recognition returns the most specific class. Redacting a general class also redacts its subclasses.

Entity classes have English names, but international equivalents are also detected. For example, `ssn` covers equivalent government identification numbers in other countries.

## Entity class groups

An entity class group covers several entity classes. Regulation groups are a good starting point: choose the one that matches your compliance requirements, then adjust it with specific entity classes. The Groups column in each table below shows which groups include each entity class.

| Group | Covers |
|---|---|
| `gdpr` | Personal data under the EU General Data Protection Regulation (GDPR). See [classes](#gdpr-gdpr). |
| `gdpr_sensitive` | Special categories of personal data under GDPR. See [classes](#gdpr-sensitive-data-gdpr_sensitive). |
| `hipaa_safe_harbor` | Identifiers under the HIPAA Safe Harbor de-identification method. See [classes](#hipaa-safe-harbor-hipaa_safe_harbor). |
| `cpra` | Personal information under the California Privacy Rights Act (CPRA). See [classes](#cpra-cpra). |
| `quebec_privacy_act` | Personal information under the Quebec Privacy Act (Law 25). See [classes](#quebec-privacy-act-quebec_privacy_act). |
| `appi` | Personal information under Japan's Act on the Protection of Personal Information (APPI). See [classes](#appi-appi). |
| `appi_sensitive` | Special care-required personal information under APPI. See [classes](#appi-sensitive-data-appi_sensitive). |
| `health` | All entity classes in [Protected health information (PHI)](#protected-health-information-phi) |
| `pci` | All entity classes in [Payment card information (PCI)](#payment-card-information-pci) |
| `pii` | All entity classes in [Personally identifiable information (PII)](#personally-identifiable-information-pii). This is a broad group that includes dates, times, amounts of money, and organization names. |

The `pci` group only covers payment-specific classes. Cardholder names and account numbers fall under `name` and `account_number`, which you can add alongside `pci`.
