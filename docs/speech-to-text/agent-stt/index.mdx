# Overview

Agent STT is transcription designed for building voice agents. Stream audio in and receive speaker-labelled, turn-based transcription back — punctuated and ready to pass to an LLM.

There are three ways to use it:

- Integration partners (LiveKit, Pipecat and VAPI): the fastest path to a production voice agent.
- Agent STT SDK: segmentation, turn detection and speaker management handled for you in Python.
- Agent STT API directly: full control for custom pipelines or working outside of supported integration platforms.

## Features

- **Turn detection**: detect when a speaker has finished talking.
- **Intelligent segmentation**: group partial transcripts into clean, speaker-attributed segments.
- **Diarization**: identify and label different speakers.
- **Speech signals**: receive signals for start and end of speech.
